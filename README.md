# Floor

Effective-state security ratings for onchain collateral, with bounded enforcement.

> "Kelp's attacked bridge route had one checker for 12.5 months. Every lender accepted rsETH anyway."

Floor continuously grades who or what can create or release a collateral asset, how many independent parties must agree, and how fast those settings can change. It encodes Aave's DAO-approved risk framework as code, and lets lenders act on the grade automatically, without ever moving funds or blocking repayments or liquidations.

Built at ETHGlobal Mumbai (Nov 5–7 2026).
